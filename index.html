WeaverBird CLI Downloads

Official releases of the WeaverBird command-line interface

Quick Install

Debian/Ubuntu (DEB package):

wget https://github.com/weaverbird-io/downloads/releases/latest/download/weaverbird-cli-linux-amd64.deb
sudo dpkg -i weaverbird-cli-linux-amd64.deb

Linux (Binary):

wget https://github.com/weaverbird-io/downloads/releases/latest/download/weaverbird-cli-linux-amd64.tar.gz
tar -xzf weaverbird-cli-linux-amd64.tar.gz
sudo mv weaverbird /usr/local/bin/
